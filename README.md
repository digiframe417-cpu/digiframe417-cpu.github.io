# DIGIFRAME — site vitrine

Site de l'agence digitale DIGIFRAME (Abidjan, Côte d'Ivoire).

**En ligne :** https://digiframe417-cpu.github.io

## Contenu
- `index.html` — la page du site
- `styles.css` — le design (ordinateur, tablette, téléphone)
- `script.js` — menu mobile et formulaire (WhatsApp / e-mail)
- `assets/` — logo et photos

## Mettre à jour le site
Modifiez les fichiers puis envoyez-les sur GitHub : le site se met à jour en 1 à 2 minutes.

Photos des services et secteurs : [Unsplash](https://unsplash.com) (licence gratuite).
